# Slowtape

**Музыкальный плеер для Android без рекламы. Любой трек в Slowed + Reverb одной кнопкой.**

### ⬇️ [Скачать Slowtape.apk](https://github.com/Noxksilor/Mobile-NoApk/releases/latest/download/Slowtape.apk)

---

## Что умеет

- **Slowed + Reverb одной кнопкой.** Замедление и эхо зала, как в slowed-версиях, для любого трека с телефона. Плюс Nightcore и ручная настройка скорости, тона и реверба.
- **Ноль рекламы.** У приложения нет даже разрешения на интернет, так что реклама и слежка невозможны в принципе.
- **Вся музыка с телефона.** Сам находит треки, чистит мусор в названиях вроде `(mp3cut.net)` и достаёт исполнителя из «Исполнитель - Трек».
- **Удобно.** Избранное, недавние, плейлисты, исполнители, альбомы, поиск, сортировка.
- **Играет в фоне.** Управление из шторки, с экрана блокировки и с наушников.
- **Таймер сна.**
- **Звук:** усилитель громкости и эквалайзер с пресетами.
- **Жанры и «Собрать плейлист»** по запросу вроде «фонк без slowed».
- **Перенос плейлистов** из старого плеера в одну кнопку.

## Как установить

1. Скачай [Slowtape.apk](https://github.com/Noxksilor/Mobile-NoApk/releases/latest/download/Slowtape.apk) на телефон.
2. Открой файл. Если Android спросит, разреши установку из этого источника.
3. Запусти Slowtape и разреши доступ к музыке.

Новые версии ставятся поверх старых, плейлисты и избранное сохраняются.

Требуется Android 8.0 или новее.
